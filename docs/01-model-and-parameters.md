# 运动学模型、代价模型与参数说明

本服务在本地模拟一台**差分驱动（differential-drive）**移动机器人，在二维占用栅格中完成全局规划与局部轨迹跟踪。所有几何量单位为米/弧度/秒。

## 1. 坐标系与占用栅格

- 世界坐标 `(x, y)`，原点 `origin=(ox, oy)` 位于地图**左下角**；`resolution` 为每格边长（米）。
- 内部存储为行主序字节数组，第 0 行对应世界 y 最大的一行（与 ASCII 地图自上而下阅读一致）。格值 `0=空闲`、`1=占用`。
- 世界→格：`col=floor((x-ox)/res)`，`row=height-1-floor((y-oy)/res)`。
- **地图边界之外一律视为占用**：任何轨迹都不可能穿出地图。
- 机器人 footprint 建模为半径 `robot_radius` 的圆盘；碰撞检测把外接框覆盖到的每个栅格做“圆心到格方形”的精确距离判定，结果与朝向无关、无方向性漏检。

## 2. 运动学约束（`app/kinematics.py`）

状态 `(x, y, θ, v)`，控制 `(v, κ)`：

| 参数 | 含义 | 默认 |
|---|---|---|
| `max_linear_speed` | 最大线速度绝对值 (m/s) | 1.0 |
| `max_angular_speed` | 最大角速度绝对值 (rad/s) | 1.0 |
| `max_curvature` | 最大瞬时曲率 (1/m)，=1/最小转弯半径 | `ωmax/vmax` |
| `robot_radius` | 圆盘外形半径 (m) | 0.15 |
| `max_linear_accel` | 最大线加速度 (m/s²)，用于相邻周期限速 | 1.0 |
| `dt` | 控制/步进周期 (s) | 0.1 |

执行前每条指令都经过统一钳制，保证同时满足：

```
|v'| ≤ vmax
|κ'| ≤ κmax
|ω'| = |v'·κ'| ≤ ωmax
```

物理一致性校验：`vmax·κmax ≤ ωmax`，否则建会话即以 `INVALID_KINEMATICS` 拒绝。

单步采用**精确圆弧积分**（非欧拉），避免大曲率漂移：

```
Δθ = v·κ·dt
x' = x + (sin(θ+Δθ)-sin θ)/κ
y' = y + (cos θ - cos(θ+Δθ))/κ
```

`|κ|` 极小时退化为直线积分；角度归一化到 `(-π, π]`。

差分底盘支持**原地自转**：`v=0` 且显式给定 `ω` 时仅改变朝向，位置不变，仍受 `ωmax` 约束。用于起步对准与终点朝向对准。

## 3. 全局规划与代价模型（`app/planner.py`）

### 3.1 障碍膨胀（配置空间）

按 `robot_radius` 对障碍做**精确欧氏膨胀**：计算每个空闲格**中心**到“障碍格矩形并集”的欧氏距离，距离 ≤ 半径即标记不可行；地图边界同样按半径封闭。

- 距离场由行扫描 + 列方向带半格截断的 Felzenszwalb 抛物线包络两遍求得，复杂度 **O(W·H)**，对 500×500 地图约 0.3 秒。
- 关键细节：距离是相对障碍**矩形边缘**（半格偏移），而非格心；这与 `disk_collides` 的几何严格一致，避免“贴边漏半格”导致半径较粗的机器人穿过本不可通过的窄缝。单测以暴力枚举距离在数百张随机地图上逐格校验。
- 8 邻接 A* 中对角移动要求两个正交邻格都可通行，**禁止切角**穿过两个障碍的夹角。

### 3.2 A* 代价

- 移动代价：直线 1、对角 √2（单位：格）。
- 启发式：octile 距离 `dx+dy+(√2-2)·min(dx,dy)`，可采纳且一致，保证最优。
- 起终点若只落在膨胀层（实体不碰墙），在 `snap_tolerance_cells`（默认 3 格）内吸附到最近可行格，吸附事件在响应 `notes` 中返回（`start_snapped`/`goal_snapped`）。

### 3.3 拒绝原因（可区分）

| 场景 | 错误码 | HTTP |
|---|---|---|
| 起/终点在地图范围外 | `COORDINATE_OUT_OF_BOUNDS` | 422 |
| 起点圆盘与障碍相交 | `START_IN_OBSTACLE` | 422 |
| 终点圆盘与障碍相交 | `GOAL_IN_OBSTACLE` | 422 |
| 膨胀后不存在连通路径 | `GOAL_UNREACHABLE` | 422 |
| 超过 `time_budget` 或 `max_expansions` | `PLAN_TIME_BUDGET_EXCEEDED` | 408 |

实体碰撞先于膨胀判定，因此“起点在墙里”和“起点贴墙但被膨胀封闭”给出不同原因。

## 4. 局部跟踪（`app/tracker.py`）

纯追踪（Pure Pursuit）+ 多重安全闸：

1. 维护最近路径点索引 `progress`（允许小幅回看，防止索引回退抖动）。
2. 沿折线累计弧长取前方 `lookahead` 处的插值目标点。
3. 曲率 `κ = 2·sin α / Ld`，经运动学包络钳制。
4. 速度曲线：随 `|κ|/κmax` 与朝向偏差增大而降速，最低保留 `min_speed_fraction`；接近目标按 `dist/dt` 减速；相邻周期受最大加速度约束。
5. 大朝向偏差（`pre_align_threshold`，默认 0.35 rad）先**原地自转**对准路径，再行驶。
6. 进入目标容差圆后刹停；若给定目标朝向则原地自转对准（容差 `heading_tolerance`），再宣告到达。

### 4.1 轨迹安全不变量

每个控制周期对**实际执行弧段**按间距 `collision_spacing`（默认 `min(res/2, robot_radius)`）密集采样，逐点在**当前地图（含动态障碍）**上做圆盘碰撞检测。候选指令按激进程度依次尝试：

`pursuit → slow（半速）→ creep（爬行）→ stop（停止）`

- 任一移动候选不安全就降级；全部移动候选不安全但原地安全 → 本周期不移动，返回 `blocked`，原因 `path_obstructed_ahead`，触发会话层重规划。
- 另有**路径前瞻预警**：沿剩余路径检查 `path_horizon`（默认 0.6 m）内的折线点，提前看到前方路径被动态障碍占据即停车重规划，不必等鼻尖撞上。
- 当前位置已被障碍覆盖 → `obstructed`（不移动），交由上层失败恢复。

因此：**任何被真正执行的状态都不穿越障碍，且速度/曲率/角速度始终不超过包络。**

## 5. 可调参数汇总

建会话时可覆盖：

- 规划：`planner_time_budget`（秒，默认 2）、`max_expansions`（默认 2,000,000）。
- 跟踪：`lookahead`（默认 0.3 m）、`goal_tolerance`（默认 0.05 m）、`heading_tolerance`（0.08 rad）、`path_horizon`（0.6 m）。
- 运动学：`kinematics` 对象各字段；`dt` 也可逐会话设置。
